⇧ Import from HubSpot / a spreadsheet (CSV)

Load the deals your team has already researched so search results get flagged In pipeline instead of being re-researched from scratch. Rows already tracked here (matched by EIN, or by funder name) are skipped, so re-importing an updated export is safe.

Recognised columns (any order, case-insensitive): Deal Name/Funder, Deal Stage/Status, Amount, Close Date/Deadline, Funder EIN, Contact, Notes, Eligibility Notes. This is the same shape the Export button produces, so an export → HubSpot → re-export round trip imports cleanly.
